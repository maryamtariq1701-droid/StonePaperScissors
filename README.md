🎮 Rock, Paper, Scissors Game
A classic web-based Rock, Paper, Scissors game built using HTML, CSS, and JavaScript. Play against the computer, track your scores, and see who wins!

🚀 Features
Interactive UI with clean styling.

Play against a computer opponent with random choice generation.

Real-time score tracking for both the User and Computer.

Dynamic message display showing winning/losing outcomes and the moves made.

🛠️ Technologies Used
HTML5: Structure of the game interface.

CSS3: Styling, layout, and visual design.

JavaScript (ES6+): Game logic, DOM manipulation, event listeners, and score management.
